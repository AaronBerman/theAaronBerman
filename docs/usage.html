theAaronBerman usage

Personal resume site for theaaronberman.com on GitHub Pages.

Install

No build. From the repo root, open home.html or serve the folder with any static file server.

Commands

Open home.html in a browser
# or
npx --yes serve .

Limits

  • Do not invent jobs, dates, or metrics. Resume files live in resources/.
  • Apache 2.0. Do not switch the license.
