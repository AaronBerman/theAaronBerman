# theAaronBerman

Personal resume site for [theaaronberman.com](https://theaaronberman.com), hosted on GitHub Pages.

A longer command reference is in [docs/usage.html](docs/usage.html).

## Structure

- `index.html` — redirects to the site
- `home.html` — main page content
- `styles/styles.css` — Start Bootstrap Resume theme (includes Bootstrap 4.5)
- `resources/` — photo, resume files, favicon
  - `Aaron_BermanResume_StreamingOps.pdf` / `.docx` — streaming / media ops targeted resume
  - `Aaron_BermanResume_ProgrammerAnalyst.pdf` / `.docx` — programmer / analyst targeted resume

## Local preview

Open `home.html` in a browser, or serve the folder with any static file server. No build step.
